# 🧠 Забывашка

> **Забывашка помнит за тебя.**

Android-приложение, которое не даёт выйти из дома с мыслью «а выключил ли я утюг?». Напоминание не отключается свайпом — только после подтверждения: фото объекта или отметка «проверено».

---

## 💡 Как это работает

1. Добавляешь объект (например, «Утюг») и фотографируешь его.
2. Назначаешь время проверки — например, 08:00.
3. В 08:00 приходит будильник с фото объекта.
4. Смахнуть нельзя — нужно сфотографировать объект заново или нажать «Проверено».
5. Только после подтверждения будильник замолкает — и ты выходишь спокойно.

**Механика:** напоминание → обязательное подтверждение → уверенность при выходе.
